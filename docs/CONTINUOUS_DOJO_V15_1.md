# JCSQE 演習道場 v15.1

## 参考にした操作思想
情報処理試験ドットコムの「過去問道場」のうち、JCSQEに適する次の考え方を参考にした。

- 出題範囲を決めた後は、問題数を毎回指定せず連続して解く
- ランダム出題だが、同じ問題を一巡前に重複させない
- 回答直後に正誤と解説を確認し、そのまま次の問題へ進む
- 未回答だけ、弱点・復習対象、分野指定で出題できる
- 学習履歴を1問ごとに保存する
- 中断した位置から再開できる
- 網羅度と正誤履歴を別に確認できる

参考:
- https://www.itpassportsiken.com/ipkakomon.php
- https://www.itpassportsiken.com/doujouManual.html

## JCSQE向けの変更
過去問道場の完全コピーではない。

JCSQEでは公式公開問題が本試験の一部だけなので、通常演習にはv15の独自400問を使用する。
出題形式はJCSQE公式サンプル・第18/20/22/26回公開問題をアンカーにする。

通常演習:
- 400問を連続出題
- 問題数選択なし
- 出題対象: おすすめ / 未回答 / 弱点概念 / 復習時期 / 保存問題
- 分野・テーマ指定可
- 1問ごとに回答を自動保存
- 選択肢位置をシャッフル
- 一巡前に同じ問題IDを重複させない
- 一巡後は次の周へ進む
- △自己申告なし
- 曖昧さは別問題での回答回数・正誤・時間を空けた再確認から判断

本番校正:
- 通常演習とは分離
- 40問・60分固定
- 途中解説なし
- 10回400問を初回得点で評価

## 達成度
学習履歴では次を表示する。

- 網羅度: 解答済みユニーク問題 / 400
- 弱点概念数
- 復習時期の概念数
- 別事例で定着確認できた概念数
- テーマごとの回答回数
- テーマごとの正解回数
- 最新状態: 要復習 / 再確認中 / 安定確認

一度の正解を「習得」とは扱わない。
