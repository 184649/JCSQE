## 今回修正した内容（v12.2）

### A12-003 エラー・フォールト・故障
選択肢が三者の対応を答える形式なのに、設問が「フォールトに当たるもの」だけを尋ねる表現だった。
設問を「エラー・フォールト・故障の対応として適切なもの」に修正した。

### A12-005 / A12-006 信頼性
初級シラバス Ver.3.0 は 1.3 で MTBF を明示しているが、MTTR は学習対象語として明示していない。
内容自体の誤りではなかったが、試験範囲に対して補助知識の比重が高かったため、MTBFを中心に再設計した。
A12-005 は「総稼働時間÷故障回数」、A12-006 は「復旧速度の改善からMTBF改善を推論しない」を確認する。

### A12-014 プロセス評価
旧設問は「この結果だけからは言えないもの」を尋ねていた一方、登録正解は「最も妥当な説明」だった。
否定の向きが登録正解と一致していない明確な不具合だったため、
「この結果について最も適切な説明はどれか」に修正した。

### A12-030 レビュー指標の名称
旧選択肢は「レビュー検出率」という名称を前面に出していたが、用語名を暗記させるより測定対象と分母を理解させる方が安全である。
「レビュー工数1時間当たりの欠陥検出数を表すプロセスメトリクス」と意味そのものを答える表現へ変更した。

### A12-060 Concept drift
旧選択肢の Label shift は条件によって P(Y|X) にも変化を生じ得るため、
Concept drift の誤答候補として完全に排他的とは言い切れなかった。
また Covariate shift / Label shift は現行初級シラバスの明示語ではない。
現在は、シラバスにある Concept drift・過学習・敵対的サンプルと、
「入力分布だけが変わり同じXに対するYは維持」という現象記述で比較する。

## 再確認した代表的な内容
- Verification / Validation：規定要求への適合と、意図した用途への適合を区別。
- QMS / ISO 9001：仕組みの運用・改善と、個別製品の無欠陥保証を区別。
- TMMi / Automotive SPICE / CMMI：評価対象と適用範囲を区別。
- FMEA / FTA：故障モードから影響へ進む分析と、頂上事象から原因組合せへ遡る分析を区別。
- p / u 管理図：不適合単位の割合と、単位当たり不適合数を区別。
- 相関 / 回帰 / 因果：相関から因果を自動的に断定しない。
- 同値分割 / 境界値 / 条件組合せ / 網羅率：分母と目的を明示。
- Privacy by Design / PIA / PET：設計原則、影響評価、保護技術を区別。
- Precision / Recall：TP+FP と TP+FN の分母を区別。
- IaaS：契約条件を前提に、ゲストOS等の利用者管理範囲を確認。
- CI / カナリア：頻繁な統合・早いフィードバックと、段階展開時の停止基準を確認。

## 自動検査
- 64問、4択、登録正解、選択肢理由、ID等のデータ整合性
- 数値問題の式を独立計算して登録値と照合
- 40問演習で正解が途中表示されないこと
- 途中再開・履歴保持・計画回・オフライン動作
- 今回の修正点（A12-003/005/006/014/060）が元へ戻っていないこと

## 限界
この問題群は日科技連の公式問題ではなく、シラバスを基準にした独自問題である。
本監査は、現行データの明確な誤り・曖昧性・計算矛盾・範囲逸脱を減らすためのもので、
本試験と同一の難易度、表現、出題比率を保証するものではない。
