# 累計回答数・正解数・正解率の表示（v15.10）

通常の連続演習のトップ、問題画面、学習記録、結果画面に、現在のプロフィールの「累計回答数」「正解数」「正解率」を表示する。正解率は正解数÷累計回答数×100、小数第1位。回答が0件の場合は0問・0問・「—」。

既存の appliedStudy.history の採点済み通常演習（kind=practice、observedがfalseでなく、correctが真偽値）の履歴をそのまま集計する。復習と「分からない」も含む。旧版の問題IDも対象。未表示問題の自動採点記録、本番演習は含めない。問題を開いただけでは回答数を増やさない。

集計はメモリ上のプロフィールを読み取るだけで、新しいカウンターの保存・データ移行・リセットはしない。問題文・正解・採点ロジック・履歴形式・localStorageのキーを変更しない。本番演習中には今回の累計表示を出さず、正誤が分かる経路を作らない。

本体バージョン15.7、キーワード解説15.8、略語解説15.9は維持し、version.json の statsVersion=15.10 と画面の累計成績欄で今回の更新を識別する。
