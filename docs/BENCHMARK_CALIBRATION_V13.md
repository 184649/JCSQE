# JCSQE 本番校正 v13 設計基準

## 目的
通常演習の得点をそのまま本番得点とみなさず、公式公開問題を難易度・選択肢設計のアンカーにした固定40問×10回で、本番80%水準の安定性を確認する。

## 公式アンカー
- 初級試験要綱: https://www.juse.jp/jcsqe/content/
  - 40問
  - 60分
  - 初級シラバス Ver.3.0
  - L1〜L3
  - 合格ライン70%程度
- 初級サンプル問題: https://www.juse.jp/jcsqe/content/jcsqe_beginner_sample.pdf
- 公開済み出題解説: https://www.juse.jp/jcsqe/study/past/
- 第22回公開問題: https://www.juse.jp/jcsqe/study/past/22_syokyu_discription.pdf
- 第26回公開問題: https://www.juse.jp/jcsqe/study/past/26_syokyu_discription.pdf

公開されているのは本試験の一部であるため、本サイトの得点と本番得点を統計的に1対1対応させることはできない。
「公式公開問題準拠」は、公開問題に見られる以下の特徴を設計アンカーにする、という意味である。

## 問題設計
- 10回 × 40問 = 400問。問題IDは10回の間で重複させない。
- 170個のシラバスチェックポイントを少なくとも2回、異なる比較形式で確認。
- 340問は近接概念の比較・用語と説明の整合性判断。
- 60問は計算・事例判断・テスト入力選択などの応用問題。
- 各回に5主要分野とL1/L2/L3をすべて含める。
- 同じ分野のもっともらしい選択肢を優先し、無関係な3択を消すだけで正解しにくくする。
- 本番形式では提出まで正解・解説を表示しない。
- 再受験は復習扱い。初回得点を上書きしない。

## 「本番80%圏・高信頼」の条件
次のすべてを満たした場合に表示する。
1. 本番校正の初回40問を3回以上完了。
2. 直近3回がすべて32/40以上。
3. 直近3回がすべて60分以内。
4. 直近3回を合算した主要5分野の正答率がすべて70%以上。

これは本番80%の保証ではない。
公式は本試験40問すべてや個人別の設問得点データを公開していないため、保証に必要な統計校正ができない。
その代わり、単発80%より厳しい「複数回・分野別・時間」の条件で高信頼判定を行う。

- 日を空けて正解したテーマ数 / 32

- 直近3回の主要5分野別正答率
- 1回完走 / 3回継続 / 200問 / 8回 / 400問のマイルストーン
