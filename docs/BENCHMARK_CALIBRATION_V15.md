# JCSQE 本番校正 v15 設計基準

## なぜ v13/v14 を刷新したか
公式公開問題を再確認すると、初級は「用語の定義を1対1で当てる問題」だけではない。

公開問題で確認できる代表形式:
- 第18回: GQMについて、4つともGQMに関するもっともらしい記述から正しい説明を選ぶ。
- 第20回: 4つの空欄について、プロセスモデル等の用語の組合せを選ぶ。
- 第22回: 品質計画について、4つとも品質計画に関する記述から最も適切なものを選ぶ。
- 第26回: 多変量解析について、分析したい目的から重回帰・因子分析・クラスター分析等を選ぶ。
- 公式サンプル: 境界値分析について、仕様条件から具体的なテストデータの組合せを選ぶ。

このため、単語と定義だけを大量に対応付ける問題庫は本番校正として不十分と判断した。

## v15の400問構成
10回×40問=400問。10回の問題IDは重複しない。

- 100問 (25%): 4空欄・4概念の組合せ
  - 第20回形式をアンカー。
  - 4選択肢の各空欄がすべて異なるようにし、同じ説明の重複から実質2択になることを禁止。
- 20問 (5%): 同一テーマの記述判定
  - 第18・22・26回の構成管理問題等をアンカー。
  - 4択すべてが同じ主題について述べる。
- 220問 (55%): 目的・状況から近接する技法/モデル/活動を選ぶ
  - 第26回多変量解析問題をアンカー。
  - 選択肢は手作業で定義した「関連概念グループ」の中から選ぶ。
- 60問 (15%): 計算・テスト設計・条件判定・運用判断
  - 公式サンプル境界値問題等をアンカー。

「単語の意味をそのまま当てる」に近い同一テーマ記述問題は5%に限定。
目的・状況判断＋計算・テスト設計の問題は70%を占める。

## 選択肢品質
次を自動検査する。
- 4択の文字列がすべて異なる。
- 4空欄問題では、どの選択肢同士も少なくとも2箇所以上異なる。
- 4空欄問題の各位置で4つの候補がすべて異なる。
- 近接概念は、同じレビュー技法群、プロセス評価モデル群、統計技法群、保守分類群、プライバシー技法群等の「関連概念グループ」から選ぶ。
- 明らかに別分野の語を混ぜて消去法だけで解ける構造を減らす。

## △回答の廃止
v15では、新しい回答に「△/迷い」の入力欄を置かない。

曖昧さは自己申告ではなく、
- 同じ概念が別問題で何回出たか
- 何回正解したか
- 直近2回が連続正解か
- 正解と誤答が混在しているか
で表面化させる。

既存の過去履歴に残る△は削除しないが、新規回答では生成しない。

## 本番80%圏
単発32/40では判定しない。
- 初回40問を3回以上
- 直近3回すべて32/40以上
- 直近3回すべて60分以内
- 直近3回の主要5分野がすべて70%以上
- 2回以上問われた概念が十分増えた段階で、直近2回連続正解の安定率も確認
