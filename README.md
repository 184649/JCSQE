# JCSQE〜初級〜 v4

JCSQE初級の400問を、スマートフォン中心で学習する静的PWAです。
サーバー、Firebase、外部DBは不要です。GitHub Pagesなどの静的ホスティングだけで動作します。

## v4の最重要変更

- 起動時のユーザー名入力画面を完全に廃止
- 初回アクセス時は自動で `ユーザー1` を作成し、そのままホームを表示
- 2回目以降は前回利用したプロフィールを自動復元
- 旧v3のプロフィール・学習履歴を保持したまま利用可能
- 名前変更は「ユーザー」画面で任意に実施
- 同じ端末を複数人で使う場合のみプロフィール追加・切替を利用
- 保存領域が使えないブラウザでは入力画面に戻さず、ホームを利用可能にした上で警告を表示
- PWAキャッシュをv4へ更新し、JS/CSS参照にバージョンを付与

## 最短の利用導線

1. URLを開く
2. ホームが表示される
3. 「今日の5問」を押す

初回でもユーザー登録・ユーザー名入力は不要です。

## 主な機能

- 今日の5問
- ランダム10問
- 弱点集中10問
- 誤答復習
- 21分野の分野別演習
- 第1〜10回の40問模擬試験
- ランダム40問模試
- 正答率・学習量・分野別傾向の分析
- 途中セッション再開
- 端末内プロフィール分離
- JSONバックアップ / 復元
- オフライン利用

## データ保存

学習履歴はブラウザの `localStorage` に保存します。
サーバーへ送信しません。同一端末でもプロフィールごとに履歴を分離します。

機種変更時は「ユーザー」→「データを書き出す」でJSONを保存し、新端末で読み込んでください。

## GitHub Pagesへの更新

ZIP内のアプリファイルを既存リポジトリへすべて上書きしてください。
特に `index.html`, `app.js`, `styles.css`, `sw.js` は必ず同時に更新してください。

旧Service Workerが残っている場合、公開後の最初の表示だけ旧画面になることがあります。その場合はSafari/Chromeで一度再読み込みするか、ページを閉じて開き直してください。v4以降は更新用のキャッシュバージョンを変更しています。

詳細な検証内容は `TEST_REPORT.md` を参照してください。
