# JCSQE〜初級〜

JCSQE初級向けの完全サーバーレスPWA学習アプリです。

## 特徴

- 添付の模擬試験10回分・400問を収録
- 今日の5問 / ランダム10問 / 弱点集中10問 / 誤答復習 / 分野別演習
- 模擬試験（第1〜10回、ランダム40問）
- 40問・60分タイマー
- 正答率推移、日別学習量、分野別正答率、弱点ランキング
- 複数ローカルプロフィール（学習データはプロフィール単位で分離）
- JSONバックアップ / 復元
- PWA / オフライン用Service Worker
- Firebase、DB、独自サーバー、外部JavaScriptライブラリ不要

## GitHub Pagesへの更新方法

このZIPを展開し、以下のファイルをリポジトリの公開ルートへ置いてください。

- `index.html`
- `styles.css`
- `questions.js`
- `logic.js`
- `app.js`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

以前の版を公開済みの場合は、上記ファイルですべて置き換えてください。古いService Workerのキャッシュは新しい `sw.js` のキャッシュ名により更新されます。

## データについて

学習履歴はブラウザの `localStorage` に保存します。同じURLを複数人が利用できますが、サーバー同期はありません。

- 別端末・別ブラウザ: データは別
- 同じ端末: プロフィール単位で分離
- 機種変更: JSON書き出し → 新端末で読み込み
