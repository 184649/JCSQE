# JCSQE Dojo v2

サーバー不要の静的PWAです。GitHub Pages等の静的ホスティングで公開できます。

## 主な機能
- 添付された模擬試験 第1〜10回、合計400問を収録
- 第1〜10回を40問・60分で受験
- 弱点優先10問 / ランダム10問 / 5問だけ / 間違い復習 / 分野別
- 学習履歴から動的に弱点優先出題
- 総合正答率・14日間推移・日別学習量・分野別正答率・模試履歴
- 複数プロフィール（同一端末でも履歴分離）
- データ書き出し / 読み込み
- localStorageのみ。サーバー・Firebase・DB不要
- Service Workerによるオフライン対応
- スマホ最適化、ホーム画面追加対応

## GitHub Pages
このフォルダ内のファイルをリポジトリのルートへ配置し、
Settings → Pages → Deploy from a branch → main / root を選択してください。

## データ分離
別の利用者が別端末・別ブラウザで同じURLを使っても、学習データは各ブラウザのlocalStorageに保存されるため混ざりません。
同一端末を共有する場合は、アプリ内のプロフィールを分けてください。

## 注意
サーバーを使用しない設計のため、端末間の自動同期やパスワード認証はありません。
別端末への移行は「設定 → データを書き出す / 読み込む」を利用します。
