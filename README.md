# JCSQE〜初級〜 v7

公開URL: https://184649.github.io/JCSQE/

スマートフォンの空き時間向けの静的学習PWAです。登録・サーバー・Firebase・外部DBは不要です。

## 使い方

ホームの「3分」「5分」「15分」から3問・5問・10問を開始できます。時間は目安です。

選択肢を選び、「確信ありで回答」「迷いありで回答」で確定するまで解説は表示しません。「分からない」も記録できます。途中で閉じても再開できます。誤答・迷いは翌日以降、確信正解は間隔を空けて復習します。

「未確認分野を補完」でQMS・プロセス評価・FMEA/FTA・形式手法・要求・測定・応用計算などを練習できます。40問60分の時間制限つき演習は終了まで解説を表示せず、中断中も時間が進みます。

結果画面または「記録」から学習レポートをコピーして、ChatGPTへ貼り付けられます。チャットや他端末への自動同期はありません。

## 問題庫を正しく理解するために

従来400問は、前置き・選択肢順・Markdown区切り線の違いを除くと52種類です。これに独自補完40問を加え、92種類で演習を組みます。元の `questions.js` と各問の正解・ID・履歴は変更せず、表示時に既知の問40末尾の区切り線だけを除きます。

**公式過去問10回分ではありません。全シラバスを網羅した本番相当問題集でもありません。** 別の演習回では問題が重複する場合があります。初回／復習を区別しますが、他端末や書籍等での学習経験は判別できません。正答率を合格確率に換算しません。

## 保存とバックアップ

履歴はこれまでと同じ `jcsqe-shokyu-state-v3` に保存します。移行前の生JSONを `jcsqe-shokyu-state-v3-before-v7` へ退避し、退避や移行が失敗した場合は元のキーへ書き込みません。旧プロフィール・履歴・途中セッションを保持します。

設定からJSONを書き出し、機種変更先で別プロフィールとして復元できます。ブラウザのサイトデータを削除すると履歴が失われるため、削除前に必ずバックアップしてください。

## 更新が見えない場合

サイトを開き直してヘッダーの「v7.0」を確認してください。更新案内が表示された場合は「更新を反映」を押します。履歴を守るため、更新目的でブラウザのサイトデータを消さないでください。

## 検証

```sh
node --test tests/*.test.cjs
node --check study-core.js
node --check study-app.js
node --check supplement.js
node --check sw.js
```

GitHub Actionsで実際のリポジトリ内400問を使用して検査します。初回検査で旧データの問40に残る区切り線を検出し、表示・重複判定の互換処理と回帰テストを追加しました。元問題ファイルは変更していません。

ローカルの画面確認はChromiumへHTML/CSS/JSを直接読み込む方式で49項目を確認しています。保存領域はテスト用実装です。iPhone実機、実際のSafari保存領域、Service Workerのオフライン再開は未検証です。テスト合格は全問題の学術的正確性や本番難易度の保証ではありません。
