# JCSQE Dojo PWA (MVP)

JCSQE初級向けのモバイルファースト学習PWAです。

## できること
- 1問ずつ回答 → 即時採点・解説
- 弱点優先10問（端末内の回答履歴から出題重みを変更）
- ランダム10問
- 間違い復習
- 模擬試験40問 / 60分タイマー
- 分野別正答率
- 回答履歴をlocalStorageに保存
- Service Workerによるオフライン利用
- ホーム画面追加（PWA）
- サーバ・DB不要

## 問題データ
`questions.js` の50問は、このMVP用に作成したオリジナル練習問題です。公式過去問・市販問題集の転載ではありません。

## ローカル起動
Service Workerを試すにはHTTPサーバで起動します。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 無料公開候補
静的ファイルだけなので、以下でほぼ無料運用できます。
- GitHub Pages
- Cloudflare Pages
- Firebase Hosting の無料枠

PWAのインストールには原則HTTPSが必要ですが、上記の静的ホスティングはHTTPSに対応しています。

## iPhone
Safariで公開URLを開き、共有 → 「ホーム画面に追加」。一度読み込んだ後はキャッシュ済み画面・問題をオフラインでも利用できます。
