# JCSQE〜初級〜 v8

公開URL: https://184649.github.io/JCSQE/

通勤・待ち時間などの短い時間で、2026年11月14日のJCSQE初級に向けて学習する静的PWAです。登録・サーバー・Firebase・外部DBは不要です。

## v8の中心：3周必修コース

公式の初級シラバスVer.3.0から選んだ **170の代表チェックポイント** を、同じ設問の丸暗記にならないよう3種類の聞き方で確認します。

1. **第1周：説明 → 用語**
2. **第2周：用語 → 説明**
3. **第3周：用語と説明の組合せ判定**

各周170回答で、3周合計510回答です。さらに各周の最後に **40問・60分の確認** を行い、**32/40以上**を取るまで次の周へ進みません。したがって3周修了までの最低回答数は **630回答** です。

第3周の初回正答率85%以上かつ、3回の40問確認をすべて32/40以上で突破すると、サイト内では「準備完了ライン達成」と表示します。

**これは合格保証ではありません。** JCSQE初級は公式に40問・60分、シラバスのL1〜L3から出題され、合格ラインは70%程度です。サイト側は安全余裕を持たせて80%以上を要求します。

## 隙間時間向け

- 3問 / 5問 / 10問の短時間演習
- 3周必修コースは5問または10問単位で進行
- 途中で閉じても再開
- 「確信あり」「迷いあり」「分からない」を分けて記録
- 第1・第2周は回答後に即解説
- 第3周は5/10問のブロック終了まで正解を表示しない
- 誤答・迷いは復習対象
- 40問確認は未使用問題を優先し、前の周との重複をできるだけ避ける

## 問題庫

- 旧400問は、前置き・選択肢順・Markdown区切り線の差を除くと52種類
- 独自補完問題40問
- 3周必修コース170チェックポイント
- 元の `questions.js` と既存ID・既存正解・旧履歴は変更していません

旧400問を「本番相当10回分」とは扱いません。3周コースも公式過去問の転載ではなく、公式シラバスを参照した独自教材です。

## 学習履歴

履歴はブラウザの `localStorage` に保存します。機種変更前やブラウザデータ削除前には設定からJSONを書き出してください。

チャットとは自動同期しません。結果画面の「結果をチャット用にコピー」または「学習状況をコピー」を使って、このチャットへ貼り付けると次の学習へ反映できます。

## 自動検査

```sh
node --test tests/*.test.cjs
node --check study-core.js
node --check study-app.js
node --check course-engine.js
node --check syllabus-course.js
node --check supplement.js
node --check sw.js
```

GitHub Actionsでは実際の公開リポジトリの問題データを使い、問題形式、重複統合、旧データ移行、3周ロック、40問確認、未回答処理、正解位置シャッフル、計算問題などを検査します。

自動テストの成功は、すべての独自問題が公式と同一難易度であることや、本番合格を保証するものではありません。
