# JCSQE〜初級〜 v9

公開URL: https://184649.github.io/JCSQE/

JCSQE初級を、通勤・待ち時間に「過去問道場」のように大量演習するための静的PWAです。登録・サーバー・Firebase・外部DBは不要です。

## v9の中心：問題道場

問題道場では **772問相当** を何度でも解けます。

- **シラバス反復 680問相当**：170の代表チェックポイント × 4形式
  - 説明 → 用語
  - 用語 → 説明
  - 正しい「用語 — 説明」の組合せ
  - 誤っている「用語 — 説明」の組合せ
- **事例・計算 92種類**
  - 旧400問を重複統合した52種類
  - 独自補完40問

シラバス反復は「680個の別知識」を意味しません。同じ170項目を4方向から確認する問題バリエーションです。事例・計算問題は別途用意しています。

## 過去問道場風の使い方

出題条件を自由に組み合わせられます。

- 問題タイプ：すべて / シラバス反復 / 事例・計算
- 大分類
- 細分類
- 知識レベル：L1 / L2 / L3 / 事例・混合
- 回答状態：未回答 / 誤答 / 迷い・不明 / あとで復習
- 並び方：ランダム / 未回答優先 / 弱点優先 / 問題ID順
- 5問 / 10問 / 20問 / 40問

選択肢の位置はセッションごとにシャッフルします。回答後に解説を表示し、「確信あり」「迷いあり」「分からない」を分けて記録します。

## 公式公開問題について

JUSEがWebで公開している初級の実問題は、出題問題の一部です。アプリへ大量転載せず、問題道場からJUSE公式の公開ページへ移動できるようにしています。

- https://www.juse.jp/jcsqe/study/past/

不足分は初級シラバスVer.3.0を基準に独自問題で補っています。独自問題はJUSE公式問題ではなく、本番と同一難易度を保証するものではありません。

## 3周必修コース

問題道場とは別に、範囲の抜けを防ぐための3周コースも残しています。

170項目を3形式で一巡し、各周の最後に40問・60分の確認を行います。各40問確認は32/40以上で次へ進みます。

## 保存

学習履歴はブラウザの `localStorage` に保存します。機種変更やサイトデータ削除の前に、設定からJSONを書き出してください。

ChatGPTとは自動同期しません。サイトの学習状況をコピーしてチャットへ貼り付けることで、チャット側の学習計画へ反映できます。

## 試験直前・実戦特訓 v17.1（2026年11月2日追加）

- 入口：[`cram.html`](./cram.html)（トップページに大きな案内を追加）
- **独自の新規80問**を**40問×2回（A・Bは重複なし）**に分け、60分制限で解答する。
- 出題形式：最適／不適切な記述、複数項目の組合せ、場面からの技法選択、テスト設計、簡単な計算とデータ解釈。
- 形式の参考：日科技連の[公式公開過去問](https://www.juse.jp/jcsqe/study/past/)（第18・20・22・26回）。問題本文は転載せず独自に作成。
- 知識範囲の基準：[現行の初級シラバス Ver.3.0](https://www.juse.jp/jcsqe/content/jcsqe_beginner_syllabus_ver_3_0.pdf)。過去の公開解説はVer.2系時代の出題を含むため、対象範囲は現行に合わせて作成。
- 分野配分（模試A・Bそれぞれ）：品質の概念4、品質マネジメント8、品質技術16、専門品質6、新領域6。これは**学習用の仮配分**で、本試験の出題比率を示すものではない。
- 模試では採点まで答え・解説を表示しない。成績を初回のみ保存し、別の模試Bの初見問題は事前に開かない。誤答には**4選択肢すべての説明**を表示。
- 11月2日〜13日の12日間の復習計画と当日11月14日の最終確認、個別の誤答再演習、成績レポートのコピーに対応。
- 従来データは削除せず、既存の同一ブラウザ／同一プロフィール保存データ内に `cramStudy` フィールドとして追加。別タブの更新を検知したら上書きを防止。
- 高得点の意味づけ：独自教材内での32/40を目標とするが、**公開過去問と本番の得点換算・難度一致・合格保証はしない**。
- テスト：`node --test tests/cram-v17.test.cjs`（80問の形式、2回の分離、分野配分、読込、サイトリンクなどを検査）。

既存の強化問題156問と本番校正10回は残っています。直前特訓の初見A→分野別理解→初見Bという使い方を推奨します。
